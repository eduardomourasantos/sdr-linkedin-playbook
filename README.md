# SDR LinkedIn Playbook

Playbook prático para prospecção consultiva no LinkedIn com apoio do ChatGPT.

O projeto transforma uma rotina diária de SDR em um processo simples e repetível:

1. escolher o cliente ideal;
2. qualificar o lead com base em evidências;
3. escrever uma abordagem personalizada;
4. conduzir a conversa sem pressão;
5. registrar o próximo passo no CRM.

## Para quem é

Para empresas B2B que querem melhorar a qualidade da prospecção no LinkedIn sem depender de mensagens genéricas ou disparos automáticos.

## O que este projeto é

- um playbook de prospecção consultiva;
- uma biblioteca de prompts para usar no ChatGPT;
- modelos de registro e acompanhamento;
- um ponto de partida para adaptar o processo ao seu negócio.

## O que este projeto não é

- um robô que acessa ou raspa o LinkedIn;
- uma ferramenta de disparo automático;
- uma promessa de reunião, venda ou receita;
- substituto para julgamento comercial humano.

O ChatGPT ajuda a organizar o raciocínio e preparar rascunhos. A pessoa responsável revisa, decide e envia.

## Comece em cinco minutos

1. Abra [`templates/cartao-do-lead.md`](templates/cartao-do-lead.md).
2. Preencha somente informações públicas e confirmadas.
3. Use [`prompts/01-qualificar-lead.md`](prompts/01-qualificar-lead.md) no ChatGPT.
4. Se houver aderência, use os prompts de mensagem.
5. Registre resposta, interesse, próxima ação e data no CRM.

## Estrutura

```text
prompts/
  01-qualificar-lead.md
  02-convite.md
  03-primeira-mensagem.md
  04-follow-up.md
templates/
  cartao-do-lead.md
PLAYBOOK.md
```

## Princípio central

Atividade não é avanço. Convites enviados e mensagens concluídas só viram progresso quando existe resposta, interesse claro, reunião, oportunidade ou receita.
